## 1. Purpose

Resolve the governed real-data evidence boundary identified by AR-P4-013 without bypassing P2/P3/P3-008, and provide implementation-side evidence necessary for the authorized performance investigation.

This Task Order is a bounded correction/integration order under the already authorized STEP-P4-006. It does not create a new Phase or Step and does not authorize Phase 5.

## 2. Repository findings establishing the boundary

CONTROL independently confirmed:
- existing Binance Spot public REST acquisition is implemented and operationally reachable;
- `BinanceAdapter.fetch_klines()` already emits provider-neutral AcquisitionEnvelope objects;
- P3 normalization requires explicit timeframe context for canonical candle normalization;
- the current Binance historical-kline envelope does not provide sufficient explicit timeframe context for normalization;
- the existing P3/P3-008 persistence and canonical contracts already provide the required persistence boundary.

The implementation task is therefore an additive context-preservation correction at the existing provider boundary, not a new canonical contract or a second persistence path.

## 3. Producer implementation boundary

Producer SHALL:

3. preserve the existing AcquisitionEnvelope contract and provider-neutral semantics;
4. keep Binance-specific behavior inside the Binance adapter;

8. add malformed/unsupported timeframe boundary tests;

10. run the existing P2/P3 relevant regression plus P4 regression;

## 5. Controlled historical evidence target

After Producer correction, CONTROL will execute the governed P2 -> P3 -> CanonicalPersistence path.

Authoritative P4 roadmap G-4 evidence requires a 1-day BTCUSDT 15M replay. The configured P4-006 runtime currently uses EMA=20, RSI=14, ATR=14 and regime lookbacks=2/2; Market Structure requires the established 5/5 swing semantics.

CONTROL therefore establishes the minimum evaluation basis as:
- 96 consecutive closed 15M candles for the one-day replay;
- at least 20 preceding closed 15M warm-up candles for the configured EMA, giving 116 primary candles minimum for a clean warm-up + one-day evaluation sequence;
- at least 25 closed 1H candles and 7 closed 4H candles to cover the same one-day evaluation span plus one preceding closed HTF boundary.

Actual acquisition may exceed this minimum. CONTROL shall record the exact acquired and processed window.
