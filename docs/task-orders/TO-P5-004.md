## 3. Required Outcome

The completed Step must provide genuine deterministic specialist interpretation of the authoritative shared Input Snapshot for Group A.

### 3.1 S-01 — Technical

Using only facts available through the authoritative Input Snapshot and its resolvable evidence references, `S-01` must provide deterministic interpretation sufficient to represent, as applicable to the configured fact surface:

- `MA_ALIGNMENT`;
- `PRICE_VS_MA`;
- `MACD_STATE`;
- `RSI_ZONE`;
- `ADX_STRENGTH`;
- `BOLLINGER_POSITION`;
- Bollinger squeeze state using the governed bandwidth threshold/configuration.

EMA periods are configuration-driven. The implementation must not silently hard-code a new period set or invent new P4 mathematical definitions.

Indicator divergence is **out of scope for this Step**. It must not be approximated through an undocumented shortcut or inferred from insufficient series evidence.

### 3.2 S-06 — Multi-Timeframe

`S-06` must deterministically interpret the authoritative Group-A facts independently by timeframe.

The implementation must:

- preserve timeframe identity and provenance;
- operate on the authoritative fact surface rather than recomputing P4 mathematical truth;
- produce explicit `CONFLUENCE`, `CONFLICT`, or `PARTIAL` outcomes where the defined input conditions permit;
- admit a higher-timeframe fact only when its authoritative temporal boundary satisfies the no-lookahead rule;
- reject or explicitly classify post-boundary/future evidence;
- represent a missing required timeframe as explicit `INSUFFICIENT_DATA` for that timeframe and the resulting overall `PARTIAL` state where applicable.

The exact implementation mechanism is left to the Producer, subject to these semantic requirements.

### 3.3 S-08 — Volatility

`S-08` must provide deterministic volatility interpretation from authoritative Group-A facts, including:

- `LOW` / `NORMAL` / `HIGH` volatility classification;
- `EXPANDING` / `CONTRACTING` state using the authoritative percentile/ratio facts and governed thresholds;
- `HIGH_VOLATILITY` as an explicit risk flag where its conditions are met.

No volatility indicator or statistical estimator outside the authoritative P4 Group-A fact vocabulary may be silently introduced.

## 5. Stage-1 Independence

This Step remains within the established Stage-1 independence model.

Each specialist receives the authoritative shared Input Snapshot and its permitted evidence references only.

In particular:

- `S-06` must not consume `S-01` output as an upstream fact;
- `S-08` must not consume `S-01` or `S-06` output;
