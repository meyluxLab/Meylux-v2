## 4. Specialist responsibilities

### S-03 — Volume Analyst

Implement deterministic interpretation of authoritative volume facts, including the governed RVOL/volume semantics already defined by the project.

The specialist shall, within the existing contract:

- identify the applicable volume facts for the current governed timeframe;
- classify the relevant volume condition, including spike/climax behavior where defined;
- relate the latest authoritative volume facts to the relevant price/candle movement facts available in the Input Snapshot;
- preserve explicit unavailable/insufficient states where required facts are absent;
- emit evidence references resolving to actual authoritative records.

No new volume mathematics may be invented. Existing P4 mathematical definitions remain authoritative.

### S-17 — Volume Profile Reasoner

Implement deterministic interpretation of the existing persisted Volume Profile facts.

The specialist shall support the governed semantics defined for S-17, including:

- price position relative to Value Area: `INSIDE / ABOVE / BELOW`;
- nearest applicable POC / VAH / VAL / HVN / LVN and distance where available;
- prior-session POC return semantics only when the required persisted session history exists;
- explicit `INSUFFICIENT_DATA` when the required number of sessions or authoritative facts is unavailable.

The specialist must consume existing persisted Volume Profile truth. It must not recompute or redefine Volume Profile mathematics.

## 5. Input and evidence boundary

Specialists consume only the authoritative Stage-1 Input Snapshot / governed input facts permitted by the Phase-5 architecture.

Every finding requiring evidence must carry a valid `CTR-P5-EVIDENCE-REF` resolving to real persisted evidence, preserving:

- source family;
- record ID;
- identity hash;
- event time;
- knowledge time;
- timeframe;
- venue.

No invented record IDs, hashes, timestamps, venue values, or evidence references are permitted.

EvidenceRef temporal semantics must remain consistent with the authoritative SnapshotFact.

No future evidence may leak into an `as_of` result.

## 6. Specialist independence

S-03 and S-17 are independent Stage-1 specialists.

They must not consume each other's outputs.

They must not consume outputs from later specialists.

They must not perform cross-specialist synthesis, final scoring, trading decisions, capital decisions, or P6 reasoning.

Any genuinely unavailable upstream fact remains unavailable/insufficient; the specialist must not fabricate a fallback.

## 7. Persistence and replay

Where the existing Phase-5 specialist output contract requires persistence, outputs shall use the authoritative append-only specialist persistence boundary.

The implementation shall establish:

- deterministic output identity;
- append-only persistence;
- direct read-back;
- replay/idempotency;
- no duplicate truth rows on replay;
- no destructive update/delete;
- reproducible serialization/version metadata.

Replay must be performed against actual generated specialist evidence, not merely asserted by a unit-test fixture.
