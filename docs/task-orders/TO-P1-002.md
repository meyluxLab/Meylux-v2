Establish the reproducible container/service foundation for Meylux V2, consistent with the ratified/frozen V2 Architecture and the Phase 1 definition.

## 3. Authorized Scope

Implement only the Docker Foundation scope of `STEP-P1-002`:

- establish the governed Docker/Compose foundation;
- establish the P1 service topology required by the approved architecture;
- establish bounded service configuration and reproducible local/container execution prerequisites;
- preserve governed directories, Stable IDs, contracts, interfaces, architecture, and security boundaries;
- add/update only implementation and test artifacts legitimately required by this Step.

## 4. Explicit Non-Scope

Do not:

- redesign or modify the ratified/frozen architecture;
- modify Constitution/invariants;
- activate or implement `STEP-P1-003` or later Steps early;
- implement Phase 2+ functionality;
- activate V1 or V1 VPS/runtime;
- authorize market/provider runtime activity;
- perform trading, capital control, or autonomous execution;
- silently change Stable IDs, contracts, interfaces, schemas, or security boundaries.

1. Implemented Docker Foundation within the authorized scope.
2. Tests/self-checks applicable to the implementation.
3. A Build Report identifying every changed/created artifact, its Stable ID where applicable, actual test results, deviations, and open questions.
4. No fabricated execution or verification evidence.
