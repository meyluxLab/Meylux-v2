## 2. Objective

Correct only the identified MEXC live WebSocket subscription-acknowledgement handling defect so that the existing adapter can receive the provider's JSON subscription acknowledgement/control response without terminating the stream, then consume the subsequent protobuf market-data frame through the existing parser and provider-neutral acquisition boundary.

After correction, execute the minimum targeted tests and the applicable P2-006 end-to-end verification required to establish actual evidence for the previously blocked MEXC live-stream path and the full dual-provider live-stream collector path.

This is a defect-correction-and-reverification task. It is not a redesign task.

## 3. Accepted Finding

The following finding is accepted by CONTROL:

`D-P2-006-001`

The live MEXC server sends a JSON subscription acknowledgement before protobuf market-data frames. The current `MEXCAdapter.stream()` path passes that acknowledgement to the market-data parser, which rejects it as `MEXC_INVALID_STREAM_PAYLOAD`, terminating the stream before the protobuf frame is consumed.

The Producer's direct evidence that the actual subsequent protobuf bytes are successfully parsed by the existing parser is accepted as supporting evidence for the localization of the defect.

## 4. Authorized Correction Scope

The Producer is authorized to modify the existing MEXC live-stream implementation only as necessary to:

1. recognize the provider's subscription acknowledgement/control response;
2. prevent that acknowledgement/control response from being misclassified as a market-data payload;
3. continue the existing stream loop after a valid acknowledgement/control response;
4. pass subsequent protobuf market-data bytes through the existing parser unchanged;
5. preserve the existing provider-neutral `AcquisitionEnvelope` boundary;
6. preserve existing error taxonomy, provider isolation, bounded retry/reconnect behavior, cleanup, and observability unless a minimal code-path adjustment is strictly required for the correction;
7. add or update deterministic regression coverage specifically for the corrected acknowledgement handling and ensure the existing MEXC stream/parser tests remain green.

The correction must be minimal, localized, and consistent with the already verified MEXC adapter architecture.
