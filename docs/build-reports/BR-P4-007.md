## 3. Orchestration / temporal semantics

The orchestration boundary validates immutable closed CanonicalCandle input, constant symbol/timeframe, strict temporal order and non-overlap. It composes EMA, RSI, ATR, market structure and regime outputs without reimplementing their mathematics.

MTF alignment selects only a closed higher-timeframe candle whose close_time is <= the primary candle close_time. Future HTF observations are therefore excluded. Exact close-boundary inclusion is tested.

## 4. Persistence

QuantitativePersistence writes only to the existing Phase-4 authoritative tables:
- meylux.calculated_indicator_vectors
- meylux.market_structure_events
- meylux.market_structure_zones
- meylux.volume_profile_sessions
- meylux.market_regime_states

The implementation uses deterministic SHA-256 identity material and ON CONFLICT(identity_hash) DO NOTHING. No UPDATE/DELETE path is introduced. Decimal and UTC serialization are explicit and reject non-finite values.

Direct tests exercise stable identity and repeated persistence behavior.

## 5. Worker / Redis

The existing Redis Streams Queue/AsyncWorker boundary is reused. The quantitative worker accepts only payload contract CTR-P4-QUANT-CANDLE-CLOSE-1.0, requires closed canonical candles, invokes the orchestration facade, and persists the resulting quantitative snapshot.

Existing queue foundation supplies ACK, timeout, retry, DLQ, duplicate/idempotency and stale pending recovery semantics; those foundation behaviors remain covered by the repository regression suite.

## 6. Read-only API

A framework-neutral quantitative API contract and dependency-free HTTP adapter were added because the repository had no ratified web-framework dependency.

Only GET is accepted. POST and other methods return 405. Unsupported quantitative families, invalid limits and invalid time ranges are rejected. Responses are deterministic JSON serialization over authoritative persistence reads. No mutation method exists in the API boundary.

## 7. Replay

QuantitativeReplay delegates directly to the same orchestrator used by runtime processing and exposes a deterministic fingerprint over the immutable result. Repeated/equivalent replay inputs are directly tested for equality.
