## 2. Changed implementation

### `src/meylux/acquisition/binance.py`

- Binance REST Spot TRADE envelopes now carry explicit `"venue": "BINANCE"`.
- Binance Spot live `trade` and `aggTrade` stream envelopes now carry the same explicit venue context.
- Existing explicit venue context is accepted only when it exactly matches `BINANCE`; contradictory context fails closed as an INVALID acquisition outcome.
- Venue is attached at the provider acquisition boundary rather than derived later from `provider_id`.
- Existing trade identity, source sequence, provider identity, instrument identity, timestamps and persistence semantics remain unchanged.

### `contracts/quality_evidence.py`

- Binance TRADE quality evidence now requires explicit `BINANCE` venue context.
- A Binance TRADE without venue is rejected rather than assigned a fallback.
- `BINANCE` venue is rejected for non-Binance provider evidence.
- Existing explicit timeframe/venue extraction remains provider-neutral and deterministic.
