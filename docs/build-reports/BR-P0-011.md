2. Provider failure silently mutating unrelated provider state.
3. Redis/cache/transport becoming permanent source of truth.

5. V1/VPS/runtime becoming a V2 implementation dependency.
6. AI/LLM becoming authoritative for deterministic financial arithmetic.
7. Any component acquiring trade, leverage, account, or capital authority.
8. Lower-tier implementation/configuration overriding higher-tier constraints.
9. Design relationships being represented as runtime/verification evidence.
10. Producer work being treated as independent CONTROL verification.
11. Later Phase 0 Steps being activated outside sequential governance.
12. Future/unavailable-at-decision-time information contaminating historical/as-of state (zero lookahead).
