## 2. Exact correction implemented

The historical-volatility public parameter path now validates the positive-window boundary and explicitly rejects `window < 2` before any rolling sample variance is evaluated.

The implemented behavior is:

- `window=1` → deterministic `ValueError("window must be at least 2 for historical volatility")`;
- `window=0` remains rejected by the existing positive-period validation;
- valid `window >= 2` retains the existing sample-standard-deviation-of-natural-log-returns formula;
- annualization remains `sqrt(periods_per_year)`;
- no fallback numeric value is emitted;
- no NaN/Inf result is emitted by the corrected boundary;
- no system time, mutable state, I/O, provider access, or other external dependency was introduced.

The mathematical correction is therefore a boundary validation correction, not a change to valid-window mathematics.
