## 4. S-02 — Market Structure

S-02 reads only persisted `meylux.market_structure_events` and `meylux.market_structure_zones` plus the authoritative closed-candle close when a current-price comparison is required.

Implemented deterministic outputs:

- dominant `STRUCTURE_STATE`, preserving `UNCONFIRMED`;
- latest confirmed structural event with `knowledge_time <= snapshot.as_of`;
- protected level from persisted `BOS`, `CHOCH`, or `MSS` facts;
- current-price relation `ABOVE / BELOW / AT`;
- signed Decimal difference from current close to protected level;
