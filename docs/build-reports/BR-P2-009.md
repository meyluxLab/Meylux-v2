## 1. Executive disposition

The investigation establishes the following provider fact:

MEXC provider-declared candle finality:
UNAVAILABLE / NOT AUTHORITATIVELY ESTABLISHED

The current authoritative MEXC Spot WebSocket K-line surface exposes candle timing and OHLCV fields, but no provider-declared closed/final/finalized flag. The official MEXC Protobuf schema inspected for the current K-line channel likewise contains no finality field. The current Spot REST /api/v3/klines response contains open time and close time but no finality field.

The following values were specifically rejected as finality evidence:

- windowend / REST close time: candle time boundary, not a provider-declared finality assertion.
- windowstart: candle start boundary, not finality.
- createtime: provider event time, not finality.
- local received_at / receipt time: local operational observation, not provider truth.
- persistence time: local storage event, not provider truth.
- repeated WebSocket updates: not finality; MEXC explicitly documents that the K-line stream updates the current candle every second.
- REST row availability: endpoint presence of a row does not constitute a provider finality declaration.

Therefore:

MEXC_FINALITY: UNAVAILABLE / NOT AUTHORITATIVELY ESTABLISHED

and, under TO-P2-009 §7:

## 6. Temporal semantics and no-lookahead boundary

The investigation maintains the following distinctions:

| Quantity | Meaning in current evidence | Provider finality? |
|---|---|---|
| windowstart / open time | candle start boundary | No |
| windowend / REST close time | candle time boundary | No |
| createtime / createTime | provider event timestamp | No |
| WebSocket sendTime | provider transport/event timing field | No |
| received_at | local acquisition receipt observation | No |
| persisted_at | local persistence event | No |
| knowledge_time | explicit knowledge/finality semantic | Not present in inspected current MEXC acquisition contract |
| provider closed/final flag | authoritative provider declaration | Not supplied by inspected current MEXC Spot surfaces |

Because MEXC documents that the current K-line stream updates the current candle every second, a later observation of the same candle is not, by itself, a provider-finality assertion.

The investigation therefore does not convert elapsed time, boundary time, observation time, or persistence time into provider finality.
