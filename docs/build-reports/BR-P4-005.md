## 2. Implemented scope

The Producer implemented the three independent evidence families required by TO-P4-005.

### Volume Profile

- explicit [interval_start, interval_end) profile interval;
- positive finite Decimal price_bin_size;
- exact Decimal floor binning;
- contiguous deterministic bins across the observed price span;
- POC as maximum-volume bin with lowest-price exact tie-break;
- exact 70% Value Area target;
- expansion from POC;
- greater-volume adjacent-bin selection;
- lower-price selection on exact expansion-volume ties;
- VAL as lowest selected-bin lower bound;
- VAH as highest selected-bin upper boundary;
- configuration-driven HVN/LVN ratios;
- equality qualification for HVN/LVN thresholds;
- zero-volume bins excluded from HVN/LVN;
- explicit empty and unavailable semantics;
- deterministic replay and no-lookahead interval filtering.

### Order Flow

- canonical aggressor-side Bar Delta;
- BUY quantity positive and SELL quantity negative;
- missing aggressor evidence routed to UNAVAILABLE;
- no candle-direction inference;
- cumulative CVD over explicitly ordered closed bars;
- missing Delta represented explicitly and not converted to zero;
- explicit imbalance threshold > 1;
- exact threshold equality qualification;
- zero opposing volume routed to UNAVAILABLE without division by zero/Infinity;
- absorption requiring aggressive trade evidence plus contemporaneous opposite-side order-book evidence;
- explicit absorption volume/displacement configuration;
- rejection of traversal beyond configured displacement;
- temporal and instrument consistency checks;
- deterministic replay.

### Derivatives

- input restricted to CTR-V2-CANONICAL-DERIVATIVES;
- canonical funding rate/change exposure;
- funding velocity from ordered funding observations when prior history exists;
- canonical supplied funding velocity exposed exactly when present;
- funding acceleration from ordered velocity observations where prior velocity exists;
- open-interest exposure;
- OI delta from canonical value or ordered prior/current OI observations;
- basis exposed only from canonical basis;
- first-observation history remains INSUFFICIENT_HISTORY;
- zero/negative elapsed time remains INVALID_INPUT;
- missing canonical evidence remains explicit and is never reconstructed.

No AI/LLM interpretation, downstream intelligence synthesis, trading/execution/capital functionality, future-Step functionality, V1 mutation, VPS operation, or unrelated refactoring was introduced.

## 7. Determinism and no-lookahead

Volume Profile uses only trades inside the explicitly supplied profile interval and does not inspect future trades outside that interval.

CVD requires explicitly ordered, closed bars and rejects temporal overlap/order violations.

Derivative velocity/acceleration use only explicit current/prior canonical observations and their actual UTC timestamps. Missing history is never replaced by zero.

Repeated execution of identical complete input/configuration produces equal immutable outputs.
