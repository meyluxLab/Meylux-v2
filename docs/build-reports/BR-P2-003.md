## 4. Implementation details

### REST/bootstrap

MEXC public Spot V3 endpoints are isolated inside the adapter:
- `/api/v3/exchangeInfo`
- `/api/v3/depth`
- `/api/v3/trades`
- `/api/v3/klines`

Provider wire payloads remain raw/staging acquisition payloads. No Phase 3 validation or normalization is performed.

### WebSocket

The adapter uses the public MEXC WebSocket endpoint and emits provider-neutral envelopes for:
- trade;
- incremental depth;
- kline.

Subscription count is bounded to MEXC's documented 30-subscription connection limit. Subscription and stream parsing remain MEXC-specific inside the adapter.

### Failure handling

- HTTP 429 maps to `RATE_LIMITED` with bounded retry.
- HTTP 5xx maps to `DEGRADED` with bounded retry.
- other HTTP 4xx maps to `UNAVAILABLE`.
- transport failures map to `UNAVAILABLE` with bounded retry.
- malformed JSON / malformed provider payloads map to `INVALID`.
- exhausted WebSocket reconnects map to `DISCONNECTED`.
- provider API error payloads map to canonical `UNAVAILABLE` / `ProviderError`.

Retry/reconnect is bounded; there is no unbounded loop.
