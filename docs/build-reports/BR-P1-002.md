## 3. Service Topology

The Compose foundation defines these services:

- `db` — TimescaleDB/PostgreSQL foundation.
- `redis` — ephemeral transport/cache foundation.
- `api` — V2 application container boundary.
- `collector` — collector service container boundary only; no provider activity implemented.
- `worker-quant` — quantitative worker container boundary only; no quantitative functionality implemented.
- `worker-ai` — AI worker container boundary only; no AI functionality implemented.

All services are attached to the governed `meylux-net` bridge network. The database and Redis services have no host `ports` mappings. Database durability is represented by the named `meylux-db-data` volume.
