## 3. Implemented Contract Behavior

`contracts/canonical/candle.py` defines:

- Stable ID: `CTR-V2-CANONICAL-CANDLE`.
- Contract version: `1.0.0`.
- Immutable `dataclass(frozen=True, slots=True)` representation.
- Explicit canonical fields for instrument identity, timeframe, temporal bounds, OHLCV values, optional quote volume/trade count, close state, and provenance reference.
- `Decimal` enforcement for price and volume numeric boundaries.
- Rejection of non-finite `Decimal` values, including NaN and Infinity.
- Rejection of binary floating-point values at the authoritative numeric boundary.
- UTC-only, timezone-aware timestamp semantics.
- Rejection of ambiguous/naive timestamps.
- Rejection of invalid temporal ordering.
- Positive OHLC price requirements.
- Non-negative volume, quote-volume, and trade-count requirements.
- OHLC relationship validation (`high`/`low` envelope).
- Mandatory non-empty logical identity, timeframe, and provenance reference.
- No implicit numeric rounding or quantization; source Decimal scale is preserved.
- No provider, network, database, filesystem, or wall-clock dependency.

## 8. Deviation / Remaining Scope Condition

The frozen architecture states that every contract defines a Stable ID and that Stable IDs are governance-controlled. The repository currently contains the known `CTR-V2-CANONICAL-CANDLE` identity and the architecture references `CTR-V2-QUANT-VECTOR` and `CTR-V2-EVENT-QUANT-REQUEST`, but it does not currently provide registered identities for the other target canonical market-data contract files (`instrument.py`, `trade.py`, `orderbook.py`, `derivatives.py`) nor a contract-specific allocation procedure authorizing the Producer to invent them.

The Producer therefore did not create those additional contract identities by personal convention.

This is not treated as an architecture redesign request. It is a governance/registry completeness condition affecting the remaining contract objects. The Producer has continued with the contract whose Stable ID is already established and has stopped only the part that would require unauthorized Stable-ID invention.
