## 4. Mathematical semantics

The authoritative implementation documentation is:

docs/quantitative/P4_002_INDICATOR_SEMANTICS.md

Key decisions recorded there include:

- EMA seed = first-window SMA;
- WMA weights = 1..window;
- HMA uses floor(period/2) and floor(sqrt(period));
- RSI uses Wilder gain/loss smoothing;
- ATR uses Wilder smoothing after a first-period TR seed;
- ADX first valid value requires 2*period-1 observations;
- Bollinger standard deviation is population standard deviation;
- historical volatility uses sample standard deviation of natural-log returns and explicit annualization;
- RVOL excludes the current candle from its baseline;
- Anchored VWAP never derives its anchor from system time or mutable state.
