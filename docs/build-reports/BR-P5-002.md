## 4. EvidenceRef semantics

The authoritative structured evidence fields are:

- `source_family`
- `record_id`
- `identity_hash`
- `event_time`
- `knowledge_time`
- `timeframe`
- `venue`

`source_reference` remains descriptive provenance and is not used as a substitute.

The builder never derives `knowledge_time` from `event_time`. Both are explicit and are independently validated.

## 5. Determinism and no-lookahead

The corrected builder:

- uses explicit UTC `as_of`;
- admits `knowledge_time == as_of`;
- rejects `knowledge_time > as_of`;
- preserves event time independently;
- sorts authoritative facts deterministically;
- deduplicates exact identical records;
- rejects same-identity contradictions;
- rejects ambiguous duplicate identities;
- computes deterministic Snapshot identity and serialization;
- has no wall-clock/provider/persistence-I/O dependency.
