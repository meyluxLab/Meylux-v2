- uses explicit UTC `as_of`;
- admits `knowledge_time == as_of`;
- rejects `knowledge_time > as_of`;
- preserves event time independently;
- sorts authoritative facts deterministically;
- deduplicates exact identical records;
- rejects same-identity contradictions;
- rejects ambiguous duplicate identities;
- computes deterministic Snapshot identity and serialization;
- has no wall-clock/provider/persistence-I/O dependency.
