ADR identity convention:

```text
ADR-<DOMAIN>-<NNN>
```

where `<DOMAIN>` is a short, clear, and specific decision domain and `<NNN>` is a three-digit sequential number within that domain. Once assigned, an ADR identifier is permanent and must never be reused.

ADRs record architecture/governance decisions, rationale, affected SIDs, alternatives where applicable, approval status, and consequences.
