# Meylux V2 — Test Strategy

Status: Draft — Pre-Phase-0

Verification layers:

- Static
- Unit
- Contract
- Integration
- Failure / Negative
- Property
- Replay
- Chaos
- End-to-End
- Soak
- Production verification

Tests are scoped to the artifact and phase being verified. Passing tests do not by themselves prove production readiness without the required evidence for that gate.
