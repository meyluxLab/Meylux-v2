# Meylux V2 — AI Continuation Protocol

Status: Draft — Pre-Phase-0

A new AI joining the project must inspect the following in order:

1. Constitution
2. Master Architecture
3. Governance / Role Contract
4. Artifact Protocol
5. Current Checkpoint
6. Open Questions
7. Deferred Decisions
8. Relevant ADRs
9. Relevant Registry records
10. Latest approved artifact and evidence chain

The AI must not infer project state from hidden chat memory alone.
