## 4. Mathematical and temporal audit

CONTROL checked the documented semantics against the implementation and controlled vectors:

- EMA uses first-window SMA seeding.
- WMA uses increasing linear weights.
- HMA uses governed floor(period/2) and floor(sqrt(period)).
- RSI uses Wilder gain/loss smoothing.
- MACD signal warm-up begins only after slow EMA availability.
- ATR and ADX use explicit Wilder-style smoothing and documented warm-up.
- Bollinger Bands use documented population standard deviation.
- Historical volatility uses documented sample standard deviation of natural-log returns with explicit annualization.
- RVOL excludes the current candle from its baseline.
- VWAP uses typical price and cumulative volume.
- Anchored VWAP requires explicit `anchor_index` and does not infer an anchor from time.

The no-lookahead regression compares an input prefix with a future-extended sequence and verifies that already-emitted EMA/VWAP values do not change.
