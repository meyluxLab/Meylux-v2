## 2. Finding F-01 — Required Rule-5 edge coverage is incomplete

Severity: CORRECTION REQUIRED

TO-P4-006 §7 requires, at minimum, direct tests/evidence for the complete boundary/failure set. The current tests/test_p4_005_regime_venue.py does not directly cover all required cases.

Material gaps:
1. Configuration/version change behavior is not directly tested. The suite verifies preservation of the configuration version, but does not prove deterministic behavior under a changed configuration/version.
2. Previous-state edge matrix coverage is incomplete. The implementation has explicit branches for previous RANGE, previous INSUFFICIENT, and direct opposite-direction transitions, but the focused suite does not directly exercise the full matrix.
3. Empty evidence is not directly tested. classify(()) is an explicit input boundary and should have a deterministic evidence-backed assertion.
4. Malformed candle/input boundary is not directly tested. The implementation rejects non-CanonicalCandle values, but the focused suite does not exercise this branch.
5. Non-increasing temporal input is not directly tested. Overlap is tested, but the separate open_time <= previous.open_time rejection branch requires direct evidence.
6. VenueEvidence constructor/input validity boundaries are only partially covered. The engine has explicit invariants for invalid VenueEvidence combinations and wrong operand types that are not directly tested.
7. Unavailable/insufficient factor transition behavior around previous states is not fully exercised.

These are not cosmetic test-count requests. They map directly to explicit acceptance requirements in TO-P4-006 §7, Rule 5, and the Producer Definition of Done.

Required correction: Producer shall add focused tests that directly exercise each missing branch/semantic class and demonstrate the expected deterministic result or rejection. The correction must not weaken implementation semantics merely to satisfy tests.
