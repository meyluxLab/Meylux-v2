# Meylux V2 — Gate Definitions

Status: Draft — Pre-Phase-0

A gate closes only when its entry criteria, required structural evidence, behavioral evidence, test evidence, and operational evidence are satisfied.

No downstream phase may treat an upstream capability as VERIFIED unless the corresponding gate is CLOSED.

## Phase 0 Entry Boundary

`G-0R` is the verified formation-ratification prerequisite for entry into `PH-P0`.

`G-0R = RATIFIED / VERIFIED` is necessary for Phase 0 entry, but it is not itself Phase 0 authorization.

Formal Phase 0 authorization additionally requires the authoritative Phase 0 definition, first Step, entry/authorization criteria, and CONTROL / REVIEWER Entry Review to be present and verified in the repository.

`STEP-P0-001` is the first official Phase 0 Step and addresses Master Architecture Reconciliation. Its completion does not automatically imply architecture ratification; the required reconciliation and approval evidence must be established through the governed artifact chain.

Final gate semantics beyond this entry boundary will be frozen during architecture reconciliation.
